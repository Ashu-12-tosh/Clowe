# Return Policy

- **Window:** {{returnWindow}} from delivery. Some categories have their own; each product page shows the window for that item, and an order keeps the window it was bought with.
- **Condition:** unused, with original tags/packaging. Hygiene-sensitive items (innerwear, beauty, supplements, groceries) are non-returnable unless damaged or wrong.
- **Damaged / wrong item:** add photos while raising the return — these speed up approval.
- **Refunds:** issued to the original payment method within 5–7 business days of pickup.
- Sellers review returns first; Clowe support can step into any dispute.
